## catalogue-getdesign-md.md

Extrait de la section « Collection » de
[VoltAgent/awesome-claude-design](https://github.com/VoltAgent/awesome-claude-design),
licence MIT. Ce depot est un index : il ne contient aucun fichier `DESIGN.md`,
seulement des liens vers getdesign.md. Les soixante-huit fichiers se
telechargent donc a la demande, un par un.

Note pour les sessions distantes : getdesign.md n'est pas joignable a travers
le proxy de sortie de cet environnement. Le telechargement se fait depuis un
poste normal, ou en ajoutant le domaine a la politique reseau.
